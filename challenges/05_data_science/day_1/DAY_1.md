# Day 1: Introduction to Python Notebooks

> This task description was written locally from the supplied `day_1.ipynb`, at the repository owner's request. It is not an original task statement downloaded from Udemy.

## Goal

Practise using a Jupyter notebook to combine notes, Python code, and visible output in one document.

## Tasks

1. Open `day_1.ipynb` and select a Python kernel.
2. Display the introductory Markdown cell containing the welcome heading, Day 1 heading, and space for notes.
3. Run a code cell that prints `hitesh`.
4. Run another code cell with a `for` loop over `range(5)`.
5. In each iteration, print `this value is` followed by the current number using an f-string.
6. Check the output below each code cell and save the notebook.

## Expected output

The first code cell prints:

```text
hitesh
```

The loop cell prints:

```text
this value is 0
this value is 1
this value is 2
this value is 3
this value is 4
```

## Concepts and tools

Jupyter notebooks, Markdown and code cells, Python kernels, `print()`, `for`, `range()`, and f-strings. Anaconda is introduced as an option for obtaining Python and notebook tools.
