# Day 6: Classify Comments with TF-IDF and Logistic Regression

> This task description was written locally from the supplied `day_6.py`, at the repository owner's request. It is not an original task statement downloaded from Udemy.

## Goal

Train and evaluate a classifier that predicts whether a comment belongs to the `toxic` or `support` class using the labeled dataset generated by Day 5.

## Tasks

1. Load `youtube_comments.csv` from the Day 5 folder using a script-relative path.
2. Use the `comment` column as input text and the `label` column as the target labels.
3. Split the records into training and test sets with `test_size=0.2` and `random_state=42`.
4. Create a scikit-learn `Pipeline` with two steps: `TfidfVectorizer()` and `LogisticRegression()`.
5. Fit the pipeline on the training comments and labels.
6. Score the fitted pipeline on the test comments and labels.
7. Print the accuracy as a percentage, rounded to two decimal places.

## Expected result

For Day 5's 100-row dataset, 80 records are used for training and 20 for testing. The terminal prints a result in this format, with accuracy depending on the CSV:

```text
Model trained. Accuracy: 100.0%
```

The script then finishes. It does not ask for a new comment, display a chart, or save the trained model.

Repeated sample comments can occur in both splits, making the test easier. The reported score does not establish how well the classifier handles new kinds of comments.

## Concepts and tools

pandas, labeled text data, train/test splitting, TF-IDF features, scikit-learn pipelines, logistic regression classification, fitting, and accuracy.
