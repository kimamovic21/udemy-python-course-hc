# Day 6: Classify Comments with TF-IDF and Logistic Regression

Train a text classifier on Day 5's generated comments and report its accuracy on a held-out test split. The possible output classes are `toxic` and `support`.

Install the packages in the Python environment used by the project:

```powershell
python -m pip install pandas scikit-learn
```


## How the code works

1. `pd.read_csv(DATA_FILE)` loads the labeled comments.
2. `train_test_split()` separates text and corresponding labels into training and test sets. With 100 rows and `test_size=0.2`, this gives 80 training rows and 20 test rows.
3. `random_state=42` makes the split repeatable for the same input data. It does not fix Day 5's random comment generation.
4. `TfidfVectorizer()` learns a vocabulary and numeric TF-IDF features from the training comments.
5. `LogisticRegression()` learns to predict the class from those features. Despite its name, it is used as a classifier here.
6. `Pipeline` connects the text conversion and classifier. `model.fit(X_train, y_train)` fits both steps using the training records.
7. `model.score(X_test, y_test)` transforms the test text through the fitted vectorizer and returns the classifier's accuracy.
8. Multiplying the score by 100 converts it to a percentage for the terminal message.

Day 5 supplies the labels from predefined lists. Day 6 learns from those labeled examples rather than assigning a class based on which source list a comment came from.

## Output and interpreting accuracy

The verified result with the current CSV is:

```text
Model trained. Accuracy: 100.0%
```

This means all 20 test rows were classified correctly in that run. The program then exits and the PowerShell prompt returns; that is the expected behavior.

The dataset contains repeated selections from only 20 sample comment texts. Identical text can occur in both training and test sets, so a high score on this split is not evidence of the same performance on genuinely new comments. The percentage can change when the dataset changes. `round(..., 2)` rounds the number but does not force two displayed decimal digits.

The current script does not prompt for a custom comment, show a graph, save a model, or create any output file. The trained pipeline exists in memory while the script runs.
