# Day 4: Interactive Salary Predictor with Streamlit

> This task description was written locally from the supplied `day_4.py`, at the repository owner's request. It is not an original task statement downloaded from Udemy.

## Goal

Turn the experience/salary regression example into a local web application where a user can enter years of experience and see a salary estimate and chart.

## Tasks

1. Load the `experience_salary.csv` dataset generated by Day 2.
2. Select `YearsExperience` as the input feature and `Salary` as the target.
3. Fit a scikit-learn `LinearRegression` model to the available records.
4. Display an application title and a short instruction using Streamlit.
5. Add a numeric input for years of experience, with a minimum of `0.0`, maximum of `50.0`, and step of `0.1`.
6. Predict the salary for the entered value and display it in a success message. The working version also handles zero years and formats the estimate to two decimal places.
7. Create a Matplotlib chart with blue points for the original records and a red line for fitted predictions.
8. Add axis labels, a title, and a legend, then display the figure with `st.pyplot()`.
9. Run the application with `python -m streamlit run`, and interact with it in a browser.

## Expected result

A local web page displays the experience input, an estimated salary, and a chart titled `Salary vs Experience`. Changing the input updates the displayed estimate.

The application reads the synthetic dataset directly from Day 2. It does not modify that CSV or automatically save predictions, the model, or the chart to a file.

## Concepts and tools

Streamlit, local web applications, numeric widgets, pandas DataFrames, linear regression, model predictions, Matplotlib figures, and paths relative to the script.
