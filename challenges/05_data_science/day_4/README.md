# Day 4: Interactive Salary Predictor with Streamlit

Build a local browser interface for the salary regression example. Enter years of experience to see a formatted salary estimate, alongside the original data and fitted regression line.

[Data Science overview](../README.md) · [Challenge index](../../README.md) · [Main project overview](../../../README.md#folder-overview)

## Setup and running

Install the packages with the Python interpreter used by this project:

```powershell
python -m pip install streamlit pandas matplotlib scikit-learn
```

If Day 2's CSV is missing, generate it first from the repository root:

```powershell
python "challenges/05_data_science/day_2/day_2.py"
```

In VS Code, open `day_4.py` and press **Ctrl + S** to start its dedicated Streamlit task. Open the Local URL printed in that task's terminal, normally `http://localhost:8501`.

Alternatively, start the application manually from the repository root:

```powershell
python -m streamlit run "challenges/05_data_science/day_4/day_4.py" --server.runOnSave true
```

Open the **Local URL** printed in the terminal, normally `http://localhost:8501`. The terminal process must stay running while you use the app. Stop it with **Ctrl + C**.

The initial import error occurred because Streamlit was not installed in the project's Python environment. Using `python -m streamlit` also selects that interpreter without requiring the `streamlit` executable to be on the shell's PATH.

## Saving changes in VS Code

This app needs the Streamlit runner. The workspace's regular `python -u` Run on Save command excludes only `challenges/05_data_science/day_4/day_4.py`. A separate matching rule invokes `workbench.action.tasks.build`, which starts **Run Data Science Day 4 Streamlit**, configured as the default build task in `.vscode/tasks.json`.

The installed Run on Save version appends its `args` to the VS Code command name. Passing the task label that way caused a command-not-found error. Calling the default task without arguments avoids that issue. **Ctrl + Shift + B** can also start this task.

The first manual save starts the server in its own terminal. Later saves keep using that task, with `instanceLimit: 1` and `instancePolicy: "silent"` preventing duplicate task instances. `--server.runOnSave true` lets Streamlit rerun the app after code changes. The task runs headlessly, so open its Local URL yourself. Stop it with **Ctrl + C** in the task terminal; the next save can start it again. Other Python lessons retain their existing Run on Save behavior.

If VS Code has not picked up the new save rule, run **Developer: Reload Window**, then save `day_4.py` again. You can also start the task through **Terminal → Run Task → Run Data Science Day 4 Streamlit**.

## Input data and files

`DATA_FILE` points to [Day 2's generated CSV](../day_2/experience_salary.csv) using the script's location, so launching from the repository root or from `day_4` reads the same file.

The CSV contains `YearsExperience` and `Salary`, representing 100 synthetic practice records. Day 4 reads that shared file directly and does not need another copy beside its script.

The app does not overwrite the CSV, export predictions, or save a trained model or chart automatically. The Matplotlib figure is embedded in the browser page rather than opening in a separate desktop window.

## How the code works

1. pandas loads the CSV into a DataFrame.
2. `X = data[["YearsExperience"]]` creates a two-dimensional input table, while `y = data["Salary"]` selects a one-dimensional target.
3. `LinearRegression().fit(X, y)` fits a salary-versus-experience line to the records.
4. `st.title()` and `st.write()` display the heading and instructions.
5. `st.number_input()` accepts experience between `0.0` and `50.0`, in steps of `0.1`.
6. A one-row DataFrame with a `YearsExperience` column is passed to `model.predict()` so its feature name matches the training input.
7. `st.success()` displays the numeric estimate with thousands separators and two decimal places, including for a zero-year input.
8. Matplotlib creates the blue data points and red fitted line. `st.pyplot(fig)` embeds the figure, and `plt.close(fig)` releases it after rendering.

Widget interactions rerun the script, so the model is fitted again on the small dataset and the estimate is recalculated. The app is an introduction using synthetic data, with no separate test set or measurement of accuracy on unseen records. Inputs outside the experience range generated by Day 2 extrapolate the fitted line.

## Local adjustments to the supplied example

- The relative CSV filename was replaced with a path to Day 2's file.
- The single salary target uses a Series, so a prediction is a scalar number rather than a one-element array.
- Prediction input uses the same feature name as training, avoiding feature-name warnings.
- The original `if years_input:` skipped the valid value `0.0`. The working version calculates a result for every allowed input.
- Estimated salaries are formatted for display, and the figure is closed after rendering.
- The launch instructions and VS Code exception use Streamlit's server workflow.

If the import cannot be resolved after installation, use **Python: Select Interpreter** to choose the environment where Streamlit is installed. If the CSV is missing, run Day 2 before starting this app.
