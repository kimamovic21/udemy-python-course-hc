Challenge: Extract Text from a PDF

Goal:
- Open a local PDF file named `test.pdf` using PyMuPDF.
- Read every page and extract its text.
- Combine the extracted text into one string.
- Print the result in the terminal between separator lines.
- Close the document after reading it.
- Handle errors when the PDF cannot be opened or read.

Bonus:
- Display the number of pages processed.
- Show a clear message when the file is missing or contains no extractable text.

Teaches: PDF text extraction, third-party packages, functions, loops, strings, and exception handling.

Note: This description was created for this repository based on `day_10.py`; it is not an original task statement supplied with the Udemy lesson.
